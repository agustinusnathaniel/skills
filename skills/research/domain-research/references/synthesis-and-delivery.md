# Synthesis and Delivery

Covers Step 5 of the domain-research workflow: turning extracted frameworks into a structured, actionable document.

## Document Structure

Structure for action, not just reference:

1. **Executive framework** — the meta-model (e.g. "The 6-Layer Company OS")
2. **Per-domain sections** with consistent structure:
   - Authoritative resources table (name, URL, why authoritative)
   - Core frameworks table (framework, what it solves, mechanism)
   - Technology-shift impact section (what changes, how it changes, economic effect)
3. **Cross-cutting patterns** — orchestration layer, build vs buy, phase-based rollout
4. **Quick-reference appendix** — one table with the top resource per domain

Done when: the document opens with the executive framework, every domain section uses the same three-part structure, and the appendix table is complete.

## Delivery Format

- **Brief summary first** — 2–3 paragraphs with the key insight
- **Sections** — `##` headers for each domain
- **Tables** — pipe tables for structured comparisons
- **Actionable conclusion** — the SOPs to write first, the tools to buy, the one book to read per domain
- **Save** — write to a versioned markdown file for future reference

Done when: summary, sections, tables, actionable conclusion, and saved file are all present.

## References Section

Every multi-source research deliverable includes a dedicated references section cataloguing all sources, organized by category (domain or topic). Each entry uses proper markdown link syntax `[text](url)` — never bare URLs in tables or lists, which render inconsistently across viewers.

Done when: every source cited in the body appears in the references section as a clickable link.

## Format Conventions

- `##` headers for major sections
- Pipe tables (`| col | col |`) for comparisons and data
- Bullet lists for sequences and non-structured info
- **Bold** for frameworks and key terms
- Code blocks for any technical commands
- Conclusion and framework first, supporting detail after

Done when: a scan of the document shows headers, tables, and bolded framework names throughout, with the conclusion before the detail.
